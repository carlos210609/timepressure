# Support

For normal questions, configuration help, and feature ideas, use GitHub Issues or Discussions.

Before opening a bug report:

1. Run `python3 timepressure.py doctor`.
2. Confirm the repository is up to date.
3. Search existing Issues.
4. Remove secrets from logs.

For reproducible bugs, include the command, Python version, operating system, expected result, and actual result.

Security vulnerabilities should not be posted publicly with credentials or exploit details. See [SECURITY.md](SECURITY.md).
